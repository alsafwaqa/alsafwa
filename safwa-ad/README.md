# إعلان الصفوة للسفريات — ALSAFWA TRAVEL

إعلان موشن جرافيك رأسي مبني بـ [Remotion](https://www.remotion.dev).

- المقاس: 1080×1920، بمعدل 30 إطارًا في الثانية.
- المدة: 1331 إطارًا (44.4 ثانية).
- الصوت: مؤثرات حركة وانتقالات فقط، بلا موسيقى أو أغنية أو تعليق صوتي.
- الملف النهائي: `deliverables/alsafwa-travel-ad.mp4`، بترميز H.264 (yuv420p) وصوت AAC 48 كيلوهرتز.

## الفكرة

طائرة الشعار هي الخيط الذي يربط الفيديو كله.

- تنفصل الطائرة عن الشعار في البداية وتقطع رحلة عبر المشاهد.
- في كل مشهد تقود العين إلى العنصر التالي.
- في النهاية تعود وتهبط في مكانها داخل الشعار.

كل انتقال مشتق من عنصر في الشعار أو من المشهد السابق:

| من ← إلى | الانتقال |
| --- | --- |
| الشعار ← «وجهتك تبدأ من هنا» | مسح قطري يتبع اتجاه الطائرة، بحافة من خطَّي السرعة في الشعار |
| «هنا» ← التأشيرات | دخول الكاميرا في نقطة «هنا»، ولونها يصبح خلفية المشهد التالي |
| التأشيرات ← الوجهات الأخرى | ثلاثة أشرطة مائلة مثل خطوط السرعة |
| الكرة الأرضية ← الطيران والفنادق | الكرة تنطبق إلى خط يصبح أفق المشهد التالي |
| الطيران والفنادق ← العمرة | نجمة ثمانية تتفتح من خلف الطائرة |
| العمرة ← مصر | أشرطة السرعة بالاتجاه المعاكس للون |
| مصر ← الختام | صعود الكاميرا خلف الطائرة |
| الختام ← الشعار | قزحية تنغلق على الطائرة |

## التشغيل

```console
npm i
npm run dev        # معاينة Remotion Studio
npm run render     # تصدير out/alsafwa-travel-ad.mp4
npm run finalize   # تحويله إلى yuv420p القياسي في deliverables/ (يحتاج ffmpeg)
npm run sfx        # إعادة توليد المؤثرات الصوتية في public/sfx (يحتاج Python و numpy)
```

إذا تعذّر تنزيل متصفح Remotion تلقائيًا، فمرّر متصفحًا مثبتًا عبر `--browser-executable=<المسار>`.

## أين أعدّل؟

| ما تريد تغييره | الملف |
| --- | --- |
| نصوص كل مشهد | `src/scenes/*.tsx`، والنص مكتوب مباشرة في `<Words text="…">` |
| الألوان والخط | `src/brand.ts` |
| مدة كل مشهد وكل انتقال | `src/timeline.ts`، ثم حدّث `durationInFrames` في `src/Root.tsx` بالمجموع |
| مسار الطائرة وتوقيتاته | `src/flight.ts`، بإطارات عامة تبدأ من بداية الفيديو |
| أنواع الانتقالات | `src/transitions/presentations.tsx` |
| مواضع المؤثرات الصوتية وشدتها | قائمة `SFX` في `src/SafwaAd.tsx` |

ملاحظات:

- بعض اللحظات مرتبطة بمسار الطائرة: الحلقة حول «هنا»، وقلب البطاقات، وظهور عناصر العمرة. إذا غيّرت توقيت الطائرة في `flight.ts` فحدّث التوقيت المقابل في المشهد.
- يتحرك النص العربي كلمةً كلمة، ولا تُفكَّك حروفه أبدًا.

## الأصول وتراخيصها

- `public/brand/logo-original.png`: الشعار كما أُرسل، دون أي تعديل. الملفات `logo-ar.png` و`logo-en.png` و`logo-plane.png` هي طبقاته الثلاث مفصولة بنفس الأبعاد، وتجميعها يعيد الشعار الأصلي بكسلًا ببكسل.
- الطائرة المتحركة نسخة متجهية (vector) من طائرة الشعار، في `src/components/Plane.tsx`، ومطابَقة لها قياسًا.
- الخط: Noto Kufi Arabic، برخصة SIL Open Font License، ونصها في `public/fonts/OFL-NotoKufiArabic.txt`.
- المؤثرات الصوتية في `public/sfx/` مولَّدة برمجيًا عبر `scripts/make-sfx.py`، فلا تحتاج أي رخصة.
- Remotion مجاني للأفراد وللشركات حتى 3 موظفين. الشركات الأكبر تحتاج رخصة شركة مدفوعة، انظر <https://www.remotion.pro/license>.
